# رستا — نسخه‌ی نمایشی آنلاین

سامانه‌ی مدیریت کارهای **گالری طلای رستا** (نسخه‌ی نمایشی برای مشتری).
طراحی و توسعه: سکان

این پوشه یک وب‌سایت کامل و بدون نیاز به سرور است. روی گوشی، نسخه‌ی موبایل و روی رایانه و تبلت، نسخه‌ی کامل خودبه‌خود باز می‌شود. قابل نصب روی گوشی (PWA) هم هست.

## انتشار روی GitHub Pages

1. در github.com یک مخزن تازه بسازید (مثلاً `rasta-demo`) و آن را **Public** بگذارید.
2. در صفحه‌ی مخزن روی **uploading an existing file** بزنید و **همه‌ی محتوای این پوشه** را (نه خود پوشه را) بکشید و رها کنید؛ بعد **Commit changes**.
3. به **Settings › Pages** بروید. در بخش Source گزینه‌ی **Deploy from a branch** را بزنید، شاخه‌ی **main** و پوشه‌ی **/(root)** را انتخاب و **Save** کنید.
4. بعد از یکی‌دو دقیقه نشانی سایت آماده است:
   `https://نام‌کاربری.github.io/rasta-demo/`

برای به‌روزرسانی، فایل‌های تازه را دوباره در همان مخزن آپلود کنید.

## نکته‌های نمایش به مشتری

- **داده‌ها در مرورگر هر نفر جدا ذخیره می‌شوند.** هر چه مشتری بسازد یا تغییر دهد با تازه کردن صفحه می‌ماند، ولی برای دیگران دیده نمی‌شود.
- **بازنشانی داده‌ها:** پایین صفحه‌ی ورود یا در منوی حساب، «بازنشانی داده‌های نمایشی».
- **نمای گوشی روی رایانه:** آخر نشانی `?ui=mobile` بگذارید (برگشت: `?ui=desktop`).
- **ابزار نمایش ارائه‌دهنده:** با `?demo=1` دکمه‌ی «ابزار نمایش» پایین صفحه می‌آید (یک روز جلو، یادآوری ساعت ۱۸، آفلاین، پوسته‌ی تیره و…).
- **نسخه‌ی پیشنهادی «ساختار مسیرها»:** در پوشه‌ی `paths` است و با `…/rasta-demo/paths/` باز می‌شود؛ داده‌اش از نسخه‌ی فعلی جداست.
- دکمه‌ی «بازگشت» مرورگر و گوشی کار می‌کند و هر صفحه و کارت نشانی خودش را دارد؛ می‌شود لینک یک کارت را مستقیم فرستاد.

## ساختار

```
index.html            برنامه
install.html          راهنمای نصب روی گوشی و رایانه
guide.html            راهنمای استفاده (و rasta-guide.pdf)
paths/                نسخه‌ی پیشنهادی «ساختار مسیرها»
manifest.webmanifest  تنظیمات نصب (PWA)
sw.js                 کار بدون اینترنت
assets/app.js         منطق و صفحه‌های برنامه
assets/app.css        ظاهر
assets/fonts/         فونت وزیرمتن (مجوز OFL)
assets/img/           لوگو و آیکن‌ها
```
